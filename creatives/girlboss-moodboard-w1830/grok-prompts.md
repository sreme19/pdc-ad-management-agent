# Grok motion prompts — "Tumse Na Ho Paayega" (one per scene)

How to use each in Grok Imagine:
- **Video mode, 720p, 6s, 9:16.**
- **Reference frames:** attach in the PROMPT BAR (not the photo-edit view). Use MULTIPLE angle
  frames ONLY if they share the SAME background (same location); if the angles have different
  backgrounds, use a SINGLE frame or the video will morph/travel (S3 lesson).
- Hair phase: **dark** = origin (S1–S3), **caramel** = travel (S4–S7).
- Every prompt hard-locks identity + outfit + background and forbids speech.
